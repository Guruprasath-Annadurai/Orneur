Temporary conversation

Before you start

What a temporary conversation actually does on this server, not a privacy promise beyond what's listed here.

Conversation history
A temporary chat is excluded from your conversation list, search, and export for as long as it's active.
Data retention
The transcript still exists on the server until you close it or it expires -- this is not zero-persistence. It is not written to long-term memory, and is not kept after close/expiry, but backups, logs outside this conversation, and any process already serving this chat are not covered.
Access and model readiness
Uses the same model availability as a normal conversation -- no separate temporary-only model tier exists.

Starting creates a real session on the server. It lasts 1 hour by default, or until you close it.
