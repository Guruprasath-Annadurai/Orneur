# SYNTHETIC - NOT EVIDENCE OF ANY MODEL CAPABILITY

Everything in this directory was generated by `scripts/evalinfra_synthetic_demo.py` from a seeded pseudo-random generator. No model was run, no data from any real
benchmark was used, no network or provider was contacted, no secret exists here, and the 'preregistration' in `prereg.json` is a SYNTHETIC fixture (its `eval_version`
is `SYNTHETIC-DEMO/0`); it is NOT the repository's V2 preregistration, which remains DRAFT_NOT_FROZEN.

The per-arm success probabilities were typed into `orca/evalinfra/synthetic.py` (DEFAULT_RATES). A 'SUPPORTED' decision in `report.md` therefore only shows that the
pipeline can recover an effect that was planted by construction; it says nothing about B0/B1/B2/T1/T2 or any real model.

Regenerate: `python scripts/evalinfra_synthetic_demo.py --out-dir docs/orneur/status/evalinfra/demo` (output is byte-for-byte reproducible; a test enforces this).
Verify the chain: `python -m orca.evalinfra verify demo/result_chain.jsonl`.
