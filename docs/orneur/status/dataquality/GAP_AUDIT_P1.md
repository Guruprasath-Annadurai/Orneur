# P1 dataset-quality gap audit

Scope: `orca/dataquality/`, `orca/registry/dataset_manifest.py`, `tests/test_dataquality_*.py`. Deterministic, CPU-only, synthetic fixtures only. No training, GPU, network, provider calls or private corpora. Training stays NOT_AUTHORIZED. Closures are additive: no existing check, output shape or committed report changed (the public-SFT reports regenerate byte-identically).

| # | Capability | What existed (evidence) | What was missing | Closure (new, `tests/test_dataquality_p1_gaps.py`) |
|---|---|---|---|---|
| 1 | Provenance and usage rights per record/source | `provenance.py` (source id, license id, generator, code SHA, digest, fail closed) - `test_dataquality_provenance_teacher.py` | Only a license **id** was checked. No recorded terms or usage rights per source; a source with a "no training" licence passed. | `usage_rights.py`: `terms_id` + `usage_rights.permitted_uses/restrictions` per source; per-record `check_usage_rights` (unrecorded, unlisted or `no-<use>` => fail). CLI `usage-rights`. |
| 2 | Teacher-output licensing | `teacher_rights.py` register + `gate_lines` (UNREVIEWED seed, PERMITTED_RECORDED needs cited terms, revision coverage) - `test_gate_*` | Records did not have to **carry** a teacher-terms entry. `permitted_uses` and `restrictions` were never enforced. Model origin declared as `human`/`program` with teacher markers (`teacher`, `distilled_from`, ...) bypassed the gate. | `teacher_derivation.py`: model-derived records (generator or markers) need `teacher_terms{teacher_id, terms_record_id}` resolving to PERMITTED_RECORDED, matching terms id, covering the intended use and revision, no restriction. Unknown/unrecorded => refused. CLI `teacher-terms`. |
| 3 | Exact + near-duplicate | `dedup.py` (raw, normalised, number-masked, MinHash/LSH Jaccard, skeleton clones) - `test_dataquality_dedup.py` | Nothing. | none |
| 4 | Diversity metrics | `diversity.py`, `balance.py` (distinct-n, TTR, skeleton entropy, balance; semantic only via injected embedder) - `test_dataquality_diversity_balance.py` | Nothing. | none |
| 5 | Privacy scan | `privacy.py` over `orca.serve.dlp` / `pii_redact` (email, US phone, SSN, card, API keys, PEM, GitHub tokens, protected-corpus markers; values never echoed) - `test_dataquality_contamination_privacy.py` | Probed: international phone, JWT, Slack token, IPv4, IBAN were not flagged; URL credentials only incidentally (as email). | `privacy_extra.py` wired into `privacy.scan_lines` (`extra_patterns=True`; IBAN mod-97 and IPv4 range validated). Pattern floor, not ceiling. |
| 6 | Train/eval leakage vs frozen eval | `contamination.py` exact, near, canary, fingerprint; train-side lines only | The eval set was never shown to be the **frozen** one (no pinned digest); fingerprint set had to be supplied separately. | `frozen_eval.py`: eval must match a pinned sha256 (none => NOT_EVALUATED, mismatch => FAIL before comparing), then contamination with a fingerprint set derived from that eval. CLI `frozen-eval`. |
| 7 | Source-manifest validation | `validate_source_registry` (inside provenance only, no CLI); `manifest.py` build/verify with tamper detection - `test_dataquality_manifest_report_card.py`; `DatasetManifest` (`dataset_manifest.py`) unchanged | No standalone, strict source-manifest validator: unknown keys, empty sources, duplicate licences, missing terms accepted. | `usage_rights.validate_source_manifest` / `check_source_manifest`. CLI `source-manifest`. |
| 8 | Deterministic, byte-stable report | `report.py` (no timestamp unless `--now`, no collapsed score) - `test_report_is_deterministic_and_timestamp_only_with_now`, public-SFT regeneration test | The report had no source-manifest, usage-rights, teacher-terms or frozen-eval entries. | `report --intended-use U [--eval-sha256 D]` (opt-in, so existing reports are unchanged) adds `source_manifest`, `usage_rights`, `teacher_terms`, `frozen_eval`; byte stability tested. |

Not changed on purpose: `orca/registry/dataset_manifest.py` (its `approve/freeze` and checksum fields already cover manifest identity); `teacher_rights.gate_lines` (kept as the first-line gate); the committed teacher register (all teachers remain UNREVIEWED; no status was granted).

Limits: pattern scanners miss unlisted formats; `terms_id` and `teacher_terms` are checked for presence and consistency with the register, not for legal sufficiency; manifest/register digests are checksums, not signatures.
