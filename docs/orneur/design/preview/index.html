ORNEUR — visual review package, Light and Dark

Two official themes, the locked palette, and an interface that stays out of the way. The honest model label, citations you can open, and a visible stop control are part of the design, not afterthoughts. Specification: docs/orneur/design/ORNEUR_UI_DESIGN_SPEC.md.

What is in this package

  1. Dark desktop conversation
  2. Light desktop conversation
  3. Dark mobile conversation
  4. Light mobile conversation
  5. Full-size falcon emblem
  6. Segmented-E ORNEUR wordmark
  7. Chat composer and streaming states
  8. Sidebar and conversation history
  9. Code block and file attachment states
  10. Empty, loading, error and model-unavailable states

Changes to earlier brand decisions

  • None to the locked palette (Slate Indigo #3A4B6B, Solar Coral #FF6B57, Pale Stone #E8E4DE, near-black dark surfaces), the greeting, or the two-theme rule.
  • Derived text colours exist only where the raw brand colour fails WCAG AA as text: Light accent text #B03626, Dark accent text #FF8A78 (measured below).
  • SUPERSEDED: the falcon emblem and segmented-E wordmark below are earlier concepts. The founder-supplied official ORNEUR logo is locked (see docs/orneur/brand/BRAND_IDENTITY_LOCK.md); do not use this generator's marks.

Proposed UX defaults (not approved)

  • First visit follows the system Dark/Light preference; a later choice persists.
  • ORNEUR is the primary product brand; model identity and lifecycle are one tap away and always truthful.
  • Experimental models are never shown as production-qualified. Build order after approval: tokens, app shell, secure chat, streaming/cancel/retry, history, files, research.
